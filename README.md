## 💼 Featured Projects

### 📥 EcoTrackify — Multi-Tenant Carbon Footprint Tracking Platform
> **MERN Stack Enterprise Sustainability Tracker**
*   **Business Problem**: Organizations lack high-fidelity, real-time auditing pipelines for enterprise sustainability management and data compliance.
*   **Architecture**: Decoupled Client-Server architecture with custom React analytics widgets and a centralized Express/MongoDB data store.
*   **Tech Stack**: `React.js`, `Node.js`, `Express.js`, `MongoDB Atlas`, `JWT`, `Tailwind CSS`, `Recharts`, `Nodemailer`.
*   **Key Engineering Features**:
    *   **Secure Authentication Architecture**: Built robust multi-step authentication incorporating JWT refresh/access token rotations, email verification flows, and `bcrypt` password hashing.
    *   **Domain-Whitelisted Access**: Formulated custom MongoDB schemas and middleware to validate domain structures for dedicated business tenants.
    *   **Real-Time Visualization Pipeline**: Designed an interactive analytical data engine optimized with `Recharts` for cross-platform emission monitoring.

### 🤖 TalentMatch AI — NLP Resume Analytics Pipeline
> **Automated Screening & Semantic Optimization Architecture**
*   **Business Problem**: Traditional keyword-matching applicant pipelines miss semantic context, resulting in high false-negative screening errors.
*   **Architecture**: Lightweight micro-service pipeline combining embedded deterministic mathematical similarity engines with external generative feedback mechanisms.
*   **Tech Stack**: `Python`, `Streamlit`, `SpaCy`, `Scikit-Learn`, `Google Gemini 2.5 Flash API`, `SQLite3`, `FPDF2`.
*   **Key Engineering Features**:
    *   **Deterministic Semantic Vectorization**: Implemented `TF-IDF Vectorization` and `Cosine Similarity` computation to map applicant data against target descriptions objectively.
    *   **Heuristic Feature Tagging**: Integrated `SpaCy` pipelines featuring part-of-speech (POS) tagging for programmatic keyword extraction.
    *   **Dynamic Document Compiling**: Engineered in-memory PDF generation micro-services via `FPDF2` to structure real-time audit reports downstream from LLM calls.

### ⌨️ WordPulse — Full-Stack Typing Performance Analytics
> **Event-Driven Performance Engineering Platform**
*   **Business Problem**: Micro-interaction performance trackers often cause excessive rendering bottlenecks, destroying the accurate measurement of telemetry metrics.
*   **Architecture**: Event-driven application state tracking coupled asynchronously to an un-blocked persistent storage tier.
*   **Tech Stack**: `React.js`, `Node.js`, `Express.js`, `MongoDB (Mongoose ODM)`, `JWT`, `Axios`.
*   **Key Engineering Features**:
    *   **Decoupled State Hook Telemetry**: Built asynchronous client layers using raw event listeners hooked into decoupled state trees to isolate layout paint overhead during active entry testing.
    *   **High Velocity Ingestion Schema**: Modeled dynamic prompt pipelines leveraging `Mongoose ODM` schemas paired with automated third-party REST validation mechanisms.
